## Introduction

Learning is the universal process that connects neurons to classrooms to neural networks. This repository is a **data-driven, auto-validated survey of learning research across all academic disciplines** — not just AI/ML.

From synaptic plasticity in the hippocampus to reinforcement learning in deep networks, from Piaget's developmental stages to meta-learning algorithms, from habit formation in behavioral economics to swarm intelligence in collective systems — learning manifests in remarkably diverse forms across disciplines, yet shares fundamental principles.

This survey organizes learning research into **20 categories** (disciplines) and **8 subcategories** (aspects), providing a structured map of the entire learning research landscape. Papers are stored in [`papers.yaml`](papers.yaml) as structured data, and the README is auto-generated by [`scripts/generate_readme.py`](scripts/generate_readme.py). See [`CONTRIBUTING.md`](CONTRIBUTING.md) for how to add papers.

## Taxonomy

### Categories (Discipline — 20)

| Category | Description |
|----------|-------------|
| **cognitive-science** | Human cognition, memory, attention, perception, decision-making, mental models |
| **neuroscience** | Neural plasticity, synaptic learning, brain regions, neural networks, fMRI |
| **education** | Pedagogy, instructional design, classroom learning, educational technology, assessment |
| **developmental** | Child development, language acquisition, cognitive development, infant learning |
| **behavioral** | Behavioral economics, habit formation, operant/classical conditioning, behavior modification |
| **social-learning** | Social learning theory, observational learning, cultural transmission, peer effects |
| **language** | Language learning, linguistics, bilingualism, literacy, speech perception |
| **motor** | Motor learning, skill acquisition, procedural memory, embodied cognition, sports science |
| **emotion** | Emotional learning, affective neuroscience, emotion regulation, trauma and learning |
| **creative** | Creativity research, creative cognition, artistic learning, divergent thinking |
| **machine-learning** | Deep learning, supervised/unsupervised/RL, self-supervised, meta-learning |
| **evolutionary** | Evolution of learning, comparative cognition, animal intelligence, cultural evolution |
| **philosophy-of-mind** | Epistemology, theories of knowledge, consciousness, mental representation |
| **educational-psychology** | Motivation, self-regulation, growth mindset, zone of proximal development |
| **animal-learning** | Comparative cognition, animal memory, foraging, navigation, tool use |
| **neuromorphic** | Brain-inspired computing, spiking networks, neuromorphic engineering |
| **memory-science** | Human memory systems (episodic, semantic, procedural, working), forgetting |
| **perceptual** | Perceptual learning, sensory plasticity, visual/auditory learning, expertise |
| **collective** | Swarm intelligence, collective behavior, group learning, organizational learning |
| **health** | Health behavior change, patient education, medical training, public health learning |

### Subcategories (Aspect — 8)

| Subcategory | Description |
|-------------|-------------|
| **theory** | Theoretical frameworks, models, formalisms |
| **mechanism** | Underlying mechanisms, processes, neural correlates |
| **method** | Research methods, experimental paradigms, measurement |
| **application** | Applied settings, interventions, real-world use |
| **development** | Developmental trajectories, age effects, lifespan |
| **individual-differences** | Aptitude, intelligence, personality, cognitive style |
| **technology** | Tools, platforms, AI tutors, VR/AR, brain-computer interfaces |
| **review** | Meta-analyses, systematic reviews, surveys, bibliometric analyses |
