# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-30

### Added

#### Research Corpus
- Analysis of 13,204 papers across 20 academic disciplines
- 98.1% saturation (157/160 taxonomy cells filled)
- Complete literature review and synthesis
- Research gap analysis
- Visualization suite (7 charts)

#### Implementation Tools
- **Platform Audit Tool** (`platform_audit.py`)
  - Interactive assessment (28 questions)
  - 7 principle scoring (0-5 scale)
  - Prioritized recommendations
  - JSON export

- **Spaced Repetition System** (`spaced_repetition.py`)
  - FSRS algorithm (17 optimized parameters)
  - Card creation and management
  - Review scheduling
  - Performance tracking
  - Statistics and analytics
  - Save/load state

- **Workshop Generator** (`workshop_generator.py`)
  - Participant handbook generation
  - Slide content creation
  - Exercise worksheets
  - Instructor notes

#### Documentation
- Implementation guides (4 documents)
- Marketing materials (3 documents)
- Research documentation (1 document)
- API reference
- Examples and tutorials

#### Platform Integration
- TypeScript SRS implementation
- Next.js API endpoints
- React UI components
- Prisma database schema
- Test suite

### Changed

- Updated contact email to ki-kompetenz-training@tobias-weiss.org
- Reorganized documentation structure
- Improved code quality and type safety
- Enhanced error handling

### Removed

- Moved workshop materials to private repository
- Separated research from production code
